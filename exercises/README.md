# Exercises

These exercises are done together by groups of 2–4 participants.

| Exercise | Duration | Description |
|---|---|---|
| [01 — Create Workspace Template](./01-create-workspace-template/) | ~30 min | Register a clickable "My Java Workspace" in the Dev Spaces dashboard |
| [02 — Team Collaboration](./02-team-collaboration/) | ~30 min | Create a shared repo, open workspaces, and collaborate on a Java project |

## Before You Start

- The [Setup](../setup/) must be completed by the instructor first
- Each participant needs `oc` access to the cluster (at minimum, developer-level access)
- Each participant needs access to a Git hosting service (GitHub, GitLab, Gitea)
- Form groups of 2–4 people

## Tips

- If you get stuck, ask your team first — discussing is part of the learning
- The `✅ Verification` sections can be expanded to check if a step succeeded
- All commands run from the Dev Spaces workspace terminal on the cluster
