Java Development on OpenShift Dev Spaces

Cloud-native Java development - from zero to productive in minutes

A hands-on workshop for teams interested in developing Java applications inside OpenShift Dev Spaces. Learn how to set up one-click developer workspaces, collaborate with your team through Git, and build Java projects entirely from the cloud - no local tooling required.

Participants work in groups of 2-4 people throughout the exercises.
