= Java Development on OpenShift Dev Spaces

A hands-on workshop for teams interested in developing Java applications inside OpenShift Dev Spaces. Participants learn to set up one-click developer workspaces, collaborate through Git, and build Java projects entirely from the cloud.

== View the Course

The full course is published at: https://juanlu-sanz.github.io/dev-spaces-workshop

== Local Development

To preview the course site locally:

[source,bash]
----
npm install
npm run dev
----

This starts a live-reload server at http://localhost:3000.

== Build the Site

[source,bash]
----
npx antora site.yml
----

The generated site is output to `gh-pages/`.

== Repository Structure

[cols="2,4",options="header"]
|===
| Directory | Purpose

| `documentation/`
| Antora courseware source (AsciiDoc pages, navigation, attributes)

| `00-setup/`
| YAML manifests for Cluster Setup - Dev Spaces operator, CheCluster, SCCs

| `01-workspace-template/`
| YAML manifests for Step 1 - Dashboard sample ConfigMap

| `supplemental-ui/`
| Custom UI overrides for the Antora site

| `lib/`
| AsciiDoc extensions (tab blocks, remote includes)
|===
